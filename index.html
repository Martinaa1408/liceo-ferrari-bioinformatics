Sfida D · Incontro 2

Scegliere la soglia

Ogni controllo costa 200 euro. Un lotto a rischio che sfugge costa 5.000 euro. Quale soglia costa meno?

  1. Per ogni soglia (0,3 · 0,5 · 0,7) conta i controlli.
  2. Conta i lotti a rischio che restano sotto la soglia.
  3. Costo = controlli × 200 + persi × 5.000. Poi il secondo round, con al massimo 10 controlli.

Esercizio 1. Calcola il contenuto AT (percentuale di A e T). Quanto fa la somma con il contenuto GC?

Aiuto

Copia il codice del contenuto GC e sostituisci G e C con A e T. La somma deve dare 1.

Soluzione
Python
# Esercizio 1: la percentuale di A e T
numero_A = dna.count("A")
numero_T = dna.count("T")
contenuto_AT = (numero_A + numero_T) / len(dna)

print(round(contenuto_AT, 2))
print(round(contenuto_GC + contenuto_AT, 2))   # deve fare 1.0
0.44 1.0

Esercizio 2. Aggiungi alla tabella AAA (K), TAG (stop, simbolo *) e GGC (G). Traduci ATGAAATAGGGC. In quale posizione compare lo stop?

Aiuto

Per aggiungere una voce a un dizionario: tabella["AAA"] = "K". Poi traduci("ATGAAATAGGGC"). Per lo stop usa .index("*"), che conta da 0: aggiungi 1.

Soluzione
Python
# Esercizio 2: aggiungi tre codoni alla tabella e traduci un'altra sequenza
tabella["AAA"] = "K"   # lisina
tabella["TAG"] = "*"   # stop: la proteina finisce qui
tabella["GGC"] = "G"   # glicina

proteina = traduci("ATGAAATAGGGC")
print(proteina)
print("Il primo stop è in posizione", proteina.index("*") + 1)

Mini-vocabolario di Python

Una variabile è un'etichetta attaccata a un valore. Una stringa è un testo tra virgolette. Un dizionario è come un vocabolario: cerchi la parola (chiave) e trovi il significato (valore). Una funzione è una procedura con un nome. Un ciclo (for) ripete un'azione. Un if sceglie tra due strade. Il simbolo # inizia un commento.

1. Il DNA è un testo

Una sequenza di DNA è una stringa, cioè un testo. Python sa misurarla e contare le lettere.

Python
# Una sequenza di DNA è solo un testo tra virgolette
dna = "ATGGTGCACCTGACTCCTGAGGAGAAG"   # l'inizio del gene dell'emoglobina beta (HBB)

print(len(dna))          # quante lettere?
print(dna.count("G"))    # quante volte compare la G?
27 9
Che cosa fa, riga per riga
  1. dna = "..." mette la sequenza in una variabile chiamata dna.
  2. len(dna) restituisce la lunghezza: 27 lettere.
  3. dna.count("G") conta quante volte compare la G: 9.
  4. print(...) mostra il risultato sullo schermo.

2. Il contenuto GC

È la percentuale di lettere G e C. Si usa per descrivere un genoma o per progettare esperimenti.

Python
# Contenuto GC: la percentuale di lettere G e C nella sequenza
numero_G = dna.count("G")
numero_C = dna.count("C")
contenuto_GC = (numero_G + numero_C) / len(dna)

print(round(contenuto_GC, 2))   # arrotonda a 2 decimali
0.56
Che cosa fa, riga per riga
  1. Contiamo le G e le C.
  2. Sommiamo i due numeri e dividiamo per la lunghezza totale.
  3. round(..., 2) arrotonda a due decimali.
  4. Controllo a mano: 9 G + 6 C = 15 lettere su 27, cioè 0,56.

3. Il codice genetico è un dizionario Curiosità

In Python la tabella del codice genetico è un dizionario. Qui ne usiamo solo 8 voci, quelle che servono per il gene dell'emoglobina. Quella completa ha 64 codoni.

Python
# Una piccola parte della tabella del codice genetico:
# a ogni gruppo di 3 lettere (codone) corrisponde un amminoacido
tabella = {
    "ATG": "M",   # metionina
    "GTG": "V",   # valina
    "CAC": "H",   # istidina
    "CTG": "L",   # leucina
    "ACT": "T",   # treonina
    "CCT": "P",   # prolina
    "GAG": "E",   # acido glutammico
    "AAG": "K",   # lisina
}

print(tabella["GAG"])
E
Che cosa fa, riga per riga
  1. Ogni riga ha la forma "codone": "amminoacido".
  2. tabella["GAG"] cerca la chiave GAG e restituisce E, l'acido glutammico.

4. Dal DNA alla proteina Curiosità

La funzione legge il DNA tre lettere alla volta e cerca ogni gruppo nella tabella. È la traduzione di una frase parola per parola con il vocabolario.

Python
# Una "ricetta" con un nome: legge il DNA 3 lettere alla volta
# e cerca ogni gruppo nella tabella
def traduci(sequenza):
    proteina = ""
    for i in range(0, len(sequenza), 3):        # 0, 3, 6, 9, ...
        codone = sequenza[i:i + 3]              # prende 3 lettere
        proteina = proteina + tabella[codone]   # cerca l'amminoacido e lo aggiunge
    return proteina

print(traduci(dna))
MVHLTPEEK
Che cosa fa, riga per riga
  1. def traduci(sequenza): definisce la funzione. Tra parentesi c'è il dato che le diamo.
  2. range(0, len(sequenza), 3) produce 0, 3, 6, 9... cioè le posizioni di inizio di ogni codone.
  3. sequenza[i:i + 3] prende 3 lettere a partire dalla posizione i.
  4. proteina = proteina + ... aggiunge l'amminoacido alla proteina costruita finora.
  5. return proteina restituisce il risultato. Sono le prime 9 lettere dell'emoglobina beta.

5. Una lettera cambia, la proteina cambia

Il codone GAG diventa GTG: l'acido glutammico (E) diventa valina (V). È la variante dell'anemia falciforme.

Python
# Cambiamo una sola lettera: la prima GAG diventa GTG
dna_mutato = dna.replace("GAG", "GTG", 1)

print(traduci(dna))          # proteina sana
print(traduci(dna_mutato))   # proteina con la mutazione
MVHLTPEEK MVHLTPVEK
Che cosa fa, riga per riga
  1. replace("GAG", "GTG", 1) sostituisce la prima GAG con GTG. Il 1 dice: una sola volta.
  2. Traduciamo le due sequenze e confrontiamo: MVHLTPEEK contro MVHLTPVEK.

6. Una regola scritta da una persona

Il machine learning cerca da solo la regola. Qui la scriviamo noi, con un if, e vediamo quante volte indovina sui 6 lotti nuovi.

Python
# Una regola scritta da una persona: se... allora...
# I 6 lotti nuovi della sfida C: (alimento, origine, stagione)
lotti_nuovi = [
    ("mais", "extra UE", "estate"),
    ("pesce spada", "UE", "estate"),
    ("riso", "UE", "estate"),
    ("mais", "UE", "estate"),
    ("mela", "extra UE", "estate"),
    ("mais", "extra UE", "inverno"),
]
# La risposta vera (lotto non conforme? sì/no), nello stesso ordine
risposte_vere = ["sì", "sì", "no", "sì", "no", "no"]

giuste = 0
for i in range(6):
    alimento, origine, stagione = lotti_nuovi[i]

    if alimento == "pesce spada" or (alimento == "mais" and origine == "extra UE"):
        previsione = "sì"
    else:
        previsione = "no"

    print(lotti_nuovi[i], "previsione:", previsione, "| vera:", risposte_vere[i])
    if previsione == risposte_vere[i]:
        giuste = giuste + 1

print("Risposte giuste:", giuste, "su 6")
('mais', 'extra UE', 'estate') previsione: sì | vera: sì ('pesce spada', 'UE', 'estate') previsione: sì | vera: sì ('riso', 'UE', 'estate') previsione: no | vera: no ('mais', 'UE', 'estate') previsione: no | vera: sì ('mela', 'extra UE', 'estate') previsione: no | vera: no ('mais', 'extra UE', 'inverno') previsione: sì | vera: no Risposte giuste: 4 su 6
Che cosa fa, riga per riga
  1. lotti_nuovi è una lista di 6 lotti. Ogni lotto è un gruppo di tre informazioni.
  2. Il for passa i lotti uno alla volta.
  3. if ... or (... and ...): è non conforme se è pesce spada, oppure se è mais extra UE.
  4. Alla fine contiamo le risposte giuste: 4 su 6. Anche una buona regola sbaglia qualcosa sui dati nuovi.

7. Recall e precisione

Due modi diversi di misurare un modello. Il recall chiede: dei lotti a rischio, quanti ne ho trovati? La precisione chiede: quando do l'allarme, quante volte ho ragione?

Python
# 100 lotti, 5 davvero a rischio. Il modello ne segnala 10
# e tra questi ce ne sono 4 davvero a rischio
a_rischio = 5
segnalati = 10
trovati = 4

recall = trovati / a_rischio          # quanti dei lotti a rischio ho trovato?
precisione = trovati / segnalati      # quando segnalo, quante volte ho ragione?

print("Recall:", recall)
print("Precisione:", precisione)
Recall: 0.8 Precisione: 0.4
Che cosa fa, riga per riga
  1. Recall = trovati / a rischio = 4 / 5 = 0,8.
  2. Precisione = trovati / segnalati = 4 / 10 = 0,4.
  3. Sono due numeri diversi e non si possono scambiare.

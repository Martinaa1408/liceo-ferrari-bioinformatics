def needleman_wunsch(a, b, match=1, mismatch=-1, gap=-2):
    n, m = len(a), len(b)
    F = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(n + 1):
        F[i][0] = i * gap
    for j in range(m + 1):
        F[0][j] = j * gap
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            s = match if a[i - 1] == b[j - 1] else mismatch
            F[i][j] = max(F[i - 1][j - 1] + s, F[i - 1][j] + gap, F[i][j - 1] + gap)
    # traceback from the bottom-right cell
    top, bottom, i, j = "", "", n, m
    while i > 0 or j > 0:
        s = match if i > 0 and j > 0 and a[i - 1] == b[j - 1] else mismatch
        if i > 0 and j > 0 and F[i][j] == F[i - 1][j - 1] + s:
            top, bottom, i, j = a[i - 1] + top, b[j - 1] + bottom, i - 1, j - 1
        elif i > 0 and F[i][j] == F[i - 1][j] + gap:
            top, bottom, i = a[i - 1] + top, "-" + bottom, i - 1
        else:
            top, bottom, j = "-" + top, b[j - 1] + bottom, j - 1
    return F, F[n][m], top, bottom

def show(a, b):
    F, score, top, bottom = needleman_wunsch(a, b)
    print("     " + "".join(f"{c:>4}" for c in "-" + b))
    for label, row in zip("-" + a, F):
        print(f"{label:>4} " + "".join(f"{v:>4}" for v in row))
    print("\nScore:", score)
    print(top)
    print(bottom)

show("GATC", "GAC")
print()
show("GAATTC", "GATTA")

Session 1

Where does a bioinformatician spend most of the day?

Data comes from the lab. The job is turning it into answers with computing, statistics and maths.

Session 1

How big is one copy of the human genome?

3.1 billion bases × 2 bits ÷ 8 is about 775 million bytes. Raw sequencer data is far bigger.

Session 1

A codon is 3 bases long. How many different codons exist?

4 × 4 × 4 = 64. There are only 20 amino acids, so several codons mean the same one, and 3 mean stop.

Session 1

Why is BLAST so much faster than Needleman-Wunsch?

BLAST only computes around short exact 'seeds'. It can miss weak similarities, but it answers in seconds.

Session 1

What does the Python code print for "ATGCGC"? (share of G and C)

Two Gs and two Cs: 4 out of 6.

Session 2

In a FASTA file, what is on the line starting with ">"?

That is the header. The sequence starts on the next line.

Session 2

100% accuracy on training data, 60% on the test set. What happened?

The model memorised the examples instead of learning a rule.

Session 2

100 batches, 5 risky. The model flags 10, including 4 of the 5. What is its recall?

Recall looks only at the truly risky batches: 4 caught out of 5. Precision is 4 out of 10, i.e. 40%.

Session 2

In food safety, which error is usually worse?

A false positive costs one extra test. A false negative can put a non-compliant product on the market.
